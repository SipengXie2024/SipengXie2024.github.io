Mechanistic Interpretability / Study Notes

消融"拒绝"

LLM 的拒绝行为，在激活空间里近似由一个单一方向编码。算出它，再把它从每层激活（或直接写入权重）中正交投影掉，模型就不再拒绝。

这是对 remove-refusals-with-transformers 参考实现与 Arditi 等人"Refusal is mediated by a single direction"工作的学习笔记， 记录方向提取、消融注入的机制，以及把这份粗糙 PoC 打磨成可靠工具的优化路线。

01

核心思路

为什么"拒绝"能被如此干净地拿掉，而不是一个模糊的权衡。

对齐训练在模型内部留下的"拒绝"行为，在高维激活空间里惊人地低维——近似一个一维子空间。 这意味着它不是散布在网络各处的复杂计算，而更像一个可以被单独定位、单独移除的"开关"。

正因如此，才能用一个线性操作（减去投影）把它剥离，而对模型其余的推理能力只造成有限损伤。 这项工作属于机制可解释性（mechanistic interpretability）：不依赖行为层面的提示词工程，而是直接读写模型内部的表征。

  • 定位：拒绝信号集中在中段某一层、最后一个 token 位置的 hidden state。
  • 表征：有害指令与无害指令在该位置的激活均值之差，即"拒绝方向"。
  • 抹除：沿该方向把激活投影到其正交补空间，拒绝信息被删除，其余信息基本保留。
02

方法：三步

参考实现的最小可行流程——方向提取、运行时消融、（进阶）权重级永久消融。

STEP 1

计算拒绝方向

用 chat template 包装一批有害 / 无害指令，各跑一次前向，取约 60% 深度那层、最后一个 token 的 hidden state， 两组激活均值相减后归一化。本质是 difference-in-means。

direction
refusal_dir = mean(harmful_hidden) - mean(harmless_hidden)
refusal_dir = refusal_dir / refusal_dir.norm()
STEP 2

运行时消融

每层前向后，把激活在拒绝方向上的分量减掉。参考实现用"插入假层"的方式实现；更干净的做法是 register_forward_hook，不翻倍层数、可随时开关。

activation hook
def ablation_hook(x, r̂):
    proj = (x · r̂) * r̂        # x 在拒绝方向上的投影
    return x - proj           # 投影到正交补空间
STEP 3

权重级永久消融

把方向直接写入权重：对所有写入残差流的投影矩阵（attention 的 o_proj、MLP 的 down_proj）左乘一个正交化算子。 改完另存为新模型，可被 llama.cpp / vLLM / ollama 等任意框架加载，零运行时开销。

orthogonalize
for W in resid_write_weights:   # o_proj, down_proj, ...
    W ← (I − r̂ r̂ᵀ) · W          # 结构性抹除该方向
03

把 PoC 打磨成工具

参考实现自称"crude"。按收益排序的优化方向如下。

  1. 01

    消融方式 → 权重级永久修改

    收益最大。避免运行时插层带来的调度开销，产出可移植的独立模型。这是社区大量 "-abliterated" 后缀模型（FailSpy 等）的标准做法。

  2. 02

    方向质量 → 扫层选优 + 更多样本

    不拍脑袋取 60% 深度，而是对所有层 × 位置扫描，按"消融后拒绝率下降 vs 能力损伤"选最优点； 样本从 32 条提到 128–256 条以压低均值噪声；必要时用 PCA 取第一主成分代替纯均值差，方向更"纯"。

  3. 03

    计算效率 → 批量前向

    拿 hidden states 不需要 generate——一次普通前向即可，跳过采样。加 padding 整批一次前向， 64 条变 1 次调用；均值累加用 float32 避免 fp16 数值误差。

  4. 04

    补上验证闭环

    量化两个指标：拒绝率（消融前后 harmful 测试集上仍含拒绝措辞的比例）与能力损伤（harmless 集上消融前后输出的 KL 散度）。在"层 × 强度系数 α"网格上选点。可选 norm-preserving 变体进一步降低能力损伤。

04

数据质量决定方向质量

方向是均值差，两组数据的任何系统性差异都会被吸进方向。四条原则。

行为真实

要的方向是"拒绝 ↔ 遵从"，不是"有害话题 ↔ 无害话题"。harmful 组只保留模型确实拒绝的， harmless 组只保留确实正常回答的——先跑一遍用关键词筛。

风格匹配

两组在长度、句式分布上尽量接近，否则句式特征混入方向、误伤正常行为。 更干净的对照：同一批有害指令，一组直接问（拒绝）、一组加越狱前缀（回答），相减只剩"拒绝"成分。

多样性

覆盖多个有害类别与无害领域，避免提取出"某类话题向量"而非通用的拒绝方向。

数量与留出

128–256 条；算方向的样本不用于最终评估，单独留 held-out 测试集测拒绝率。

05

适用边界与定位

这篇笔记是机制可解释性的学习记录，目的在理解对齐的内部结构。

学习这项技术是为了理解对齐训练在表征层面如何工作——这是可解释性研究的核心问题之一。 它揭示：安全对齐产生的某些行为是脆弱的、可被线性操作逆转的，这对评估模型鲁棒性、研究对齐的稳定性都有价值。

硬件边界：本机 8GB 显存只够 1–8B 模型的 4bit 量化（Qwen3-4B / Llama-3.1-8B）。像 DeepSeek-V4-Flash 这类 304B MoE 模型（最激进 2-bit 量化也要 ~95GB）本地不可行，但消融的数学与模型大小无关，技术在小模型上即可完整练通。

授权边界：仅在自有模型、自有硬件、学习目的下操作。本文不提供任何指向真实滥用的成品或数据。
