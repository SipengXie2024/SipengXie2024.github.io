内部安全崩塌：当"完成任务"压倒"拒绝"

LLM agent 安全笔记

ISC 是一种前沿大模型的失效模式：把模型放进一个自动化编码 Agent 的角色，让它去补全一个"缺数据的测试任务"， 模型会为了消除报错、让测试通过，而主动生成它平时会直接拒绝的有害内容。这组笔记拆解其触发框架 TVD， 再推导部署侧的防御边界。
