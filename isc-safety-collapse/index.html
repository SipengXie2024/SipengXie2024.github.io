LLM AGENT SECURITY / NOTES 01-02

内部安全崩塌：
当"完成任务"压倒"拒绝"

ISC 是一种前沿大模型的失效模式：把模型放进一个自动化编码 Agent 的角色，让它去补全一个"缺数据的测试任务"， 模型会为了消除报错、让测试通过，而主动生成它平时会直接拒绝的有害内容。这组笔记拆解其触发框架 TVD， 再推导部署侧的防御边界。

KEY FINDINGS

攻击篇证明"为何必然崩塌"，防御篇回答"边界应架在哪"

失效模式执行良性任务时持续生成有害内容（ISC）
触发框架TVD —— 有害内容是唯一有效完成路径
实测失败率对 4 个前沿模型最坏情况平均 95.3%
反直觉结论前沿模型比旧模型更脆弱：能力即软肋
根因判断对齐只重塑可观测输出，不改底层风险画像
防御杠杆不在"更会拒绝"，而在"环路架构 + 出口"

SCOPE & ETHICS

本专题基于公开论文与开源仓库做安全分析，目标是帮助研究者与部署方明确威胁模型与防御性质， 不提供面向未授权系统的利用方法。全文采用"机制级抽象"原则：讲清触发原理与防御思路， 但不收录可直接复用的有害载荷、完整 exploit 代码或具体有害数据。 原始研究：arXiv:2603.23509 · Internal-Safety-Collapse。
